# Prueba Manual de Usabilidad

Estado: pendiente de ejecución con una persona que no haya usado la página.

## Protocolo

1. Entregar la URL publicada o local sin explicar la interfaz.
2. Pedir: "Con una promoción de 15% y tope de reintegro de 10000, encontrá el importe seguro de compra".
3. Iniciar cronómetro al entregar la consigna.
4. Registrar si la persona ingresa ambos valores, obtiene resultados e identifica "Máximo seguro de compra" sin ayuda ni navegación adicional.
5. Detener cronómetro cuando identifique el importe seguro.

## Criterio de éxito

La persona completa la tarea en 60 segundos o menos e identifica `$66.666,66` como el máximo seguro.
