- (direction by user) Modo guiado; unico entregable: arquitectura para implementacion.
- (constraint) PRD final y UX final son fuentes vinculantes; aplicacion estatica HTML/CSS/JS, sin backend, persistencia, cuentas ni integraciones.
- (constraint by user) Responsive completo: debe verse y funcionar bien en desktop y mobile; 320x568 y 1280x720 son puntos minimos de verificacion, no los unicos anchos validos.
- (constraint) Logica de validacion y calculo debe ejecutarse y probarse sin DOM; calculos solo en memoria y sin llamadas de red.
- (decision by user) Adoptar nucleo funcional + shell imperativo. Vincula toda la aplicacion; evita que unidades independientes mezclen DOM con validacion, calculo o formateo. El nucleo sera puro y la shell sera la unica propietaria de eventos y mutaciones del DOM.
- (decision by user) Usar enteros escalados y BigInt para toda aritmetica de negocio. Vincula FR-003 a FR-010 y NFR-007; evita divergencia y errores de coma flotante. Porcentaje en centesimas, tope y resultados en centavos, cociente y residuo racionales para truncamiento y redondeo exactos.
- (decision by user) Adoptar starter oficial Vite Vanilla con Vite 8.1.5 y Vitest 4.1.10, sin framework ni dependencias de produccion. Vincula desarrollo, pruebas y despliegue; evita scripts y resolucion de modulos incompatibles. La salida dist sera un sitio estatico.
- (constraint by user) Desktop y mobile tienen la misma prioridad funcional. La responsividad debe gobernar composicion, legibilidad, controles tactiles, estados de error, resultados, formula y advertencia; no limitarse al mockup desktop.
- (version) Verificado el 2026-07-28 en registros y documentacion oficiales: Vite 8.1.5; Vitest 4.1.10; Vite ofrece starter vanilla y build de activos estaticos, y requiere Node 20.19+ o 22.12+.
- (decision) Responsive mobile-first: base desde 320px, contenedor fluido maximo 640px, resultados apilados y una media query min-width 640px para dos columnas iguales; controles minimo 44px, tamanos fluidos y ningun overflow horizontal ocultado.
- (decision) El DOM es dueno de strings de entrada y la shell es la unica duena de flags efimeros de interaccion y mutaciones. Cada evento ejecuta evaluar y luego un unico render completo; cualquier invalidez oculta ambos resultados para impedir valores parciales o obsoletos.
- (decision) Inputs type=text con inputmode=decimal y gramatica estricta antes de parsear; el nucleo devuelve union discriminada ok/error con codigos estables por campo y BigInt en centavos cuando es valido. La shell convierte codigos a microcopy y presentacion accesible.
- (decision) Todos los activos de runtime, incluida Nunito si se usa, se sirven localmente; quedan prohibidos CDN, fuentes remotas, analytics, cookies y storage. dist es autocontenido y desplegable en cualquier hosting estatico sobre HTTPS, sin API ni configuracion por ambiente.
- (decision) Pruebas Vitest importan solo el nucleo sin DOM y cubren reglas FR/AC y limites BigInt. Build fija targets chrome120, edge120, firefox120 y safari17; smoke manual responsive en 320x568, 375x667, 768x1024 y 1280x720 con teclado, mouse y tactil donde aplique.
- (version) Node.js 22.23.1 LTS verificado en nodejs.org como version vigente de la linea 22; entorno local disponible Node 24.18.0, compatible con Vite 8.1.5 y Vitest 4.1.10.
- (direction) Estructura minima: index.html, src/app.js como shell, src/calculator.js como nucleo puro, src/styles.css, tests/calculator.test.js y public/fonts para activos locales; regla de tres antes de subdividir.
- (decision) Reconciliacion endurece responsive: meta viewport obligatorio; padding de pagina de 16px con contenedor interno max-width 640px; tarjetas y celdas min-width 0; importe usa clamp(1.25rem, 7vw, 2rem) y overflow-wrap anywhere como ultimo recurso; caso maximo debe pasar sin overflow.
- (decision) Agregar @playwright/test 1.62.0 como dependencia solo de desarrollo para verificar viewport, layouts, overflow, tamanos tactiles, foco, limpiar, advertencia y estados inicial/valido/invalido/incompleto/maximo en Chromium, Firefox y WebKit; Safari y Chrome moviles reales siguen requiriendo smoke registrado.
- (decision) Todo evento input evalua sin boton Calcular. Codigo incomplete identifica sufijo decimal potencialmente completable; oculta resultados pero su mensaje se suprime mientras el campo conserva foco. Blur muestra el error; Limpiar restaura touched=false.
- (decision) Orden DOM fijo: porcentaje, tope, Limpiar, resultado teorico, resultado seguro; el layout no usa reordenamiento CSS. Ambos resultados conservan igual tipografia, dimensiones y prominencia; formula y ejemplo permanecen visibles en todos los estados.
- (decision) La advertencia colapsada conserva en summary los tres elementos esenciales de FR-019. UX visual se adjudica a favor de sus reglas prose: result-label sin letter-spacing y boton Limpiar con radio 8px. No se permiten animaciones ni transiciones.
- (decision) Gate de entrega incluye prueba de usabilidad novel en 60 segundos y reporte de versiones concretas verificadas en desktop y mobile; matriz responsive incorpora landscape, zoom/texto 200 por ciento y estados expandidos y de error.
- (version) @playwright/test 1.62.0 verificado en npm el 2026-07-28; requiere Node 20 o superior y se usa solo en desarrollo.
- (decision) Gate fija API: named exports evaluateCalculation y formatArs; errors es objeto con discount/cap nullable y enum required, incomplete, invalid-format, too-many-decimals, out-of-range; precedencia required, incomplete, format/decimales, rango. Gramatica valida exige digitos a ambos lados del separador; ceros iniciales permitidos.
- (decision) Gate fija hooks DOM por id y mutacion in-place para preservar foco, seleccion y details; touched es por campo, se activa solo al input/blur de ese campo y errores solo se muestran para campos touched, salvo incomplete suprimido durante foco.
- (decision) Vite usa base './' y rutas de activos administradas por su grafo para que un mismo dist funcione en raiz o subruta. Playwright prueba dist bajo subruta. Fuente variable Nunito vive en src/assets y su OFL en licenses.
- (decision) Operaciones MVP: artefacto inmutable identificado por commit, rollback por redeploy previo, index sin cache durable y assets hashados immutable; sin telemetria cliente. Hosting posee HTTPS, disponibilidad y logs; postdeploy smoke sin datos de usuario.
- (decision) Compatibilidad: build incluye ios17; Playwright bundled prueba motores actuales y canales Chrome/Edge disponibles, no sustituye productos minimos. Gate MVP requiere evidencia separada de pisos y variantes reales comprometidas y prueba AT Safari+VoiceOver y Edge+NVDA.
- (decision) Medicion NFR-004 va desde entrada al listener input hasta completar mutaciones DOM sincronas; diez muestras, p95 nearest-rank ceil(0.95*n)-1. Scripts canonicos npm: dev, test, test:browser y build; zero tests es fallo.
- (version) Se adopta Node.js Active LTS 24.18.0, verificado en nodejs.org y disponible localmente; satisface engines de Vite, Vitest y Playwright.
- (decision) Cada input marca solo touched del campo editado pero siempre llama evaluateCalculation con ambos strings; blur marca su campo y rerenderiza. No hay validadores parciales alternativos.
- (decision) Contrato cierra null como sentinel con ambas keys presentes y clasificadores disjuntos: vacio, separador final, tercer decimal en formato numericamente limpio, formato restante, luego rango.
- (decision) npm 11.16.0 y package-lock versionado; toda instalacion reproducible usa npm ci. Playwright posee preview 127.0.0.1:4173 strictPort mediante webServer y baseURL; test:browser construye antes de ejecutar y zero tests falla.
- (decision) Contrato DOM fija roles de hooks, clases estructurales y status: vacio en inicial/limpiar/invalido no visible; errores visibles concatenados; valido anuncia ambos importes formateados. Render in-place conserva foco, seleccion y apertura details.

- (decision) Grafo Vite: index.html carga solo /src/app.js como module; app.js importa ./styles.css; styles.css importa fuente desde ./assets. Ninguna otra unidad publica esos edges.
- (decision) Setup browser reproducible ejecuta npx playwright install --with-deps chromium firefox webkit tras npm ci; canales branded son evidencia adicional cuando disponibles.
