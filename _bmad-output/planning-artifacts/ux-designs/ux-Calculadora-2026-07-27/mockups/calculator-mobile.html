Usa este monto para evitar superar el tope.

Fórmula

Monto teórico = Tope / (Descuento / 100)

El monto teórico se redondea a dos decimales. El máximo seguro se trunca a dos decimales para que el descuento calculado no supere el tope.

Resultado orientativo: el tope limita el descuento porcentual; revisa las condiciones reales de la promoción.

Las promociones reales pueden aplicar reglas de redondeo o condiciones específicas por transacción.
