Calculadora de tope de reintegro

Ingresa el porcentaje de descuento y el tope de reintegro para conocer cuánto conviene gastar.

Monto teórico de compra

Valor exacto redondeado a dos decimales.

Máximo seguro de compra

Usá este valor para no superar el tope.

Fórmula

Monto teórico = Tope / (Porcentaje / 100)

El monto teórico puede incluir fracciones de centavo. Se redondea a dos decimales; el máximo seguro se trunca de forma conservadora para no superar el tope.

Resultado orientativo: el tope limita el descuento porcentual; revisa las condiciones reales de la promoción.

Las promociones reales pueden aplicar reglas de redondeo o condiciones específicas por transacción.

Ejemplo

Con 15% de descuento y un tope de $10.000:

Monto teórico

$66.666,67

Máximo seguro

$66.666,66
